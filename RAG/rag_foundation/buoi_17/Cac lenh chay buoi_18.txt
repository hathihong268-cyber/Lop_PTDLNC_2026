1. DI CHUYỂN VÀO THƯ MỤC DỰ ÁN BUỔI 18 (HOẶC BUỔI 17):

2. KÍCH HOẠT MÔI TRƯỜNG ẢO PYTHON & THIẾT LẬP ENCODING UTF-8:
   - PowerShell:
     $env:PYTHONUTF8=1
     ..\..\..\.venv\Scripts\Activate.ps1
   - Command Prompt (CMD):
     set PYTHONUTF8=1
     ..\..\..\.venv\Scripts\activate.bat

3. CHẠY GIAO DIỆN WEB STREAMLIT UI (UC3, UC4, AUDIT TRAIL):
   streamlit run app.py --server.port 8501
   (Truy cập ứng dụng trên trình duyệt web tại địa chỉ: http://localhost:8501)

4. CHẠY CORE ENGINE UC3: AI COMPLIANCE CHECKER (SO SÁNH CHÉO QUY ĐỊNH)
   python scripts/compliance_checker.py
   (Phát hiện mâu thuẫn/chồng chéo quy định, gán Severity và review_status)

5. CHẠY CORE ENGINE UC4: AI AUDIT CHECKLIST GENERATOR (SINH CHECKLIST KIỂM TOÁN)
   python scripts/audit_checklist_gen.py
   (Sinh danh mục mục kiểm tra theo Domain & Unit, đính kèm Citation thật)

6. CHẠY BỘ KIỂM THỬ BẢO MẬT & GUARDRAIL 7 BÀI TEST (SECURITY TESTS B18)
   python scripts/security_tests_b18.py
   (Kiểm thử RBAC, Citation Integrity, Anti-Hallucination, Audit Privacy,...)

7. CHẠY NGHIỆM THU TOÀN BỘ DỰ ÁN BUỔI 18 (FINAL PROJECT VALIDATION)
   python scripts/final_validation_b18.py
   (Xác nhận 8 tiêu chí nghiệm thu và xuất báo cáo nghiệm thu cuối cùng)

8. LỆNH ĐỒNG BỘ MÃ NGUỒN VÀ BÁO CÁO LÊN GITHUB:
   git add .
   git commit -m "Hoan thanh va nghiem thu Buoi 18: AI Compliance Checker & AI Audit Checklist Generator"
   git push origin main
